# 🎱 3CUSHION - 免費線上撞球與三顆星開侖計分器

> 專為美式撞球 (Pool) 與開侖 / 三顆星 (3-Cushion) 設計的跨平台線上計分板工具。手機、平板開啟瀏覽器即可免費使用！

👉 **立即使用**：[https://ericwww22.github.io/3CUSHION/](https://ericwww22.github.io/3CUSHION/)

---

## ✨ 核心特色

- 📱 **即開即用**：無需下載 App，使用 iOS / Android 手機、平板或電腦瀏覽器即可操作。
- 🎱 **多種模式**：
  - **三顆星 / 開侖計分板** (`index.html`)：支援輪次統計、局數紀錄、打擊計時與平均得分率計算。
  - **美式撞球計分板** (`pool-scoreboard.html`)：支援 8-Ball、9-Ball、10-Ball 雙人對戰與勝率統計。
- 🖥️ **全螢幕支援**：提供一鍵全螢幕模式，非常適合將平板放在球桌旁作為公用計分板。
- ⚡ **輕量高效**：零廣告載入迅速，操作直覺，適合撞球館與私友對局使用。

## 🚀 使用說明

### 1. 三顆星 / 開侖計分器 (3-Cushion)
1. 造訪主頁面：[https://ericwww22.github.io/3CUSHION/](https://ericwww22.github.io/3CUSHION/)
2. 輸入選手姓名與目標分數（或預設回合數）。
3. 點擊畫面上的 **+1** / **-1** 按鈕進行即時加減分。
4. 點擊 **End Turn (結束輪次)** 自動切換選手並紀錄輪數與 AVG (平均得分率)。

### 2. 美式撞球計分器 (Pool Scoreboard)
1. 造訪美式撞球頁面：[https://ericwww22.github.io/3CUSHION/pool-scoreboard.html](https://ericwww22.github.io/3CUSHION/pool-scoreboard.html)
2. 設定對局局數（如：搶 5 勝、搶 7 勝）。
3. 點擊勝局按鈕即可即時更新局數與累計勝率。

## 📱 推薦技巧：新增至手機主畫面 (PWA 體驗)

為了獲得接近原生 App 的全螢幕體驗，建議將網頁新增至手機桌面：
- **iOS (Safari)**：點擊分享按鈕 ➔ 選擇 **「新增至主畫面」**。
- **Android (Chrome)**：點擊右上角選單 `⋮` ➔ 選擇 **「新增至主畫面」** 或 **「安裝應用程式」**。
