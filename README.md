# 黑馬撞球賽事系統

保留原型中的單敗、雙敗和循環賽、輪空／棄權、名次表、匯入匯出、列印及觀戰快照功能，並針對搶局比分、改判後晉級、誤操作與行動版操作做了優化。

## 使用

從裁判控制台更新賽事資料和名單；可使用「賽前檢查」核對賽會名稱、人數、姓名、搶局設定與輪空，再依現場完賽狀況記分。分數按每位選手的搶局數判定：尚未達標只保存為進行中，達標者才晉級；改變上游選手後，相關的下游比分會重置。對局可用分數欄或加減按鈕記錄。

## 資料與觀戰

賽事資料會自動存入目前瀏覽器的 localStorage；定期使用「匯出備份」保管 JSON。分享網址帶入產生當下的唯讀快照，可跨裝置閱讀，但裁判後續更改比分不會自動同步到已分享連結。重新產生分享快照可分享更新後資料。

本版本是前端工具，不含中央雲端資料庫、帳號登入、伺服器端權限或多裁判即時協作；唯讀是使用介面限制，不是對原始碼或資料的安全保護。請不要透過公開快照分享個人敏感資料。
